# System Component Architecture

**Project:** PRISM (Programmable Routing & Intelligent Semantic Mapper)

This document details the internal module structure required to fulfill the 4-plane architecture design.

## 1. High-Level Workflow
1. **Ingestion:** Raw network packet arrives via UDP/QUIC -> `prism-ingest`.
2. **Provenance:** Packet is hashed via BLAKE3 -> `prism-integrity`.
3. **Routing:** Packet is checked against known schemas -> `prism-map`.
   - *Match:* Converted to OCSF -> output to Elasticsearch Sink.
   - *Miss:* Sent to Dead Letter Queue (DLQ).
4. **Learning (Async):** `prism-brain` reads DLQ -> clusters (Drain3) -> classifies (Open Jev) -> drafts VRL (Ollama) -> requests admin approval.
5. **Observability:** `prism-tui` queries metrics -> renders dashboard.

---

## 2. Component Breakdown

### A. Ingestion Plane (`prism-ingest`)
**Language:** Rust
*   **`listener.rs` & `quic.rs`:** 
    *   Listens on UDP (Legacy firewalls) and QUIC (Next-Gen Telemetry) on Port 514.
    *   Implements amortized zero-copy buffering via `bytes::BytesMut` blocks (configured by `chunk_size = 10 MiB`) and uses `socket2` for strict `SO_RCVBUF` tuning.
*   **`dispatcher.rs`:**
    *   Atomically fans out `RawEvent` (containing raw `&[u8]` and in-flight BLAKE3 hash) via dual high-throughput channels (`flume`) to the Data and Provenance Planes. Handles TOCTOU backpressure safely.

### B. Data Plane (`prism-core`)
**Language:** Rust
*   **`router.rs`:**
    *   Dynamic Signature Registry: Fast heuristic packet sniffer that bypasses regex. If unmapped, fallback to `dlq.log`.
*   **`mapper.rs`:**
    *   Embeds the Vector Remap Language (VRL) execution engine.
    *   Hot-reloads VRL parsers generated by the AI Control Plane.
    *   Takes `&str` (raw log), executes VRL program, returns `serde_json::Value` (OCSF output).
*   **`sink.rs`:**
    *   Batches the OCSF JSON and pushes via HTTP POST to an external Elasticsearch/Splunk cluster for industry dashboards.

### C. Control Plane (`prism-brain`)
**Language:** Python (for AI/ML libraries)
*   **`cluster` / Drain3:**
    *   Fixed-Depth Tree CPU 1M/sec O(n) d+cm
*   **`triage` / Laya:**
    *   System1 421M 32ms GPU /120ms CPU vs heuristic 1µs
*   **`coder` / llama-server:**
    *   Q4_K_M 0.7s CPU AVX2 vs heuristic 0s

Note: watcher/gatekeeper later, decoupled for debug + per-device best perf

### D. Integrity Plane (`prism-provenance`)
**Language:** Rust
*   **`hasher.rs`:**
    *   Implements `blake3` (SIMD-accelerated, configurable to FIPS `sha256`).
*   **`vault.rs`:**
    *   Batches raw logs into **Apache Parquet** format compressed with Zstd for ultra-cheap 180-day retention.
    *   Maintains the **Merkle Tree** root to guarantee chain-of-custody for intelligence audits.

### E. Presentation Plane (`prism-tui`)
**Language:** Rust (Ratatui)
*   **`ui.rs`:**
    *   Renders the 4-pane terminal dashboard (Live EPS, DLQ, AI Drafts, Integrity Ticker).
