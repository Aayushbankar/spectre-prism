# `prism-tui`

The `prism-tui` crate provides the Presentation Plane (Plane 5) interface. It is a highly optimized, low-overhead terminal dashboard built using Ratatui, designed for real-time situational awareness on headless servers or edge nodes.

## Interface: The Engine Room
The dashboard is split into a robust 4-pane layout updating at a smooth 10Hz interval:

### Pane 1: EPS Gauge & Sparkline
- Visualizes real-time throughput (Events Per Second).
- Reads metrics without locking the main ingestion path.

### Pane 2: Dead Letter Queue (DLQ) Table
- Displays the most recent alien/unrecognized logs diverted by the Data Plane.
- Uses seek-based low-overhead file polling on `/var/run/prism/dlq.log`.

### Pane 3: Merkle Ticker & Line Chart
- Shows the latest cryptographic Merkle roots being generated by `prism-provenance`.
- Provides instant visual confirmation of the Integrity Plane's operation.

### Pane 4: HitL Gatekeeper List
- Displays pending auto-generated parsing rules (from the AI Control Plane) requiring Human-in-the-Loop (HitL) approval.

## Technology Stack
- **Ratatui (0.30)**: Powers the UI components (gauges, charts, tables).
- **Crossterm (0.29)**: Handles event polling and terminal manipulation.
- **Tokio**: Provides the asynchronous 100ms interval ticks to drive the rendering loop asynchronously without blocking log ingestion.

## How to Test & Run
To run the terminal UI in isolation or against live PRISM data:

```bash
cargo run -p prism-tui
```

Tests run headless using `TestBackend` to verify rendering logic without requiring a physical TTY:
```bash
cargo test -p prism-tui
```
