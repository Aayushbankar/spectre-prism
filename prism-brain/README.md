# `prism-brain` (Python Control Plane)

`prism-brain` implements the AI-driven Control Plane (Plane 3) for PRISM. Written in Python (3.11), it provides an asynchronous, decoupled pipeline for analyzing alien logs, semantic classification, and dynamic VRL rule generation.

## Sub-Modules

### 1. `watcher.py` (File Watcher)
Uses a dual-path `inotify` (via watchdog) mechanism.
- Monitors `/var/run/prism/dlq.jsonl` for new alien logs dropped by the Data Plane.
- Achieves near 0% CPU utilization while waiting for changes.

### 2. `cluster.py` (Template Mining)
Implements Drain3 (He et al.) for ultra-fast, O(n) fixed-depth template mining.
- Rapidly groups thousands of alien logs into a handful of distinct templates.
- Proven to process 52k logs into 7 templates in under 0.6 seconds.

### 3. `triage.py` (Semantic Classification)
Utilizes the Laya model (ModernBERT 421M, Apache 2.0).
- Classifies log templates into categories (Firewall, Web Proxy, OS, etc.).
- Evaluates dynamically: If `device:cpu` is set, or if inference latency spikes, it seamlessly falls back to a deterministic heuristic engine (<1ms).
- GPU inference averages 32.8ms; CPU averages 120ms.

### 4. `coder.py` (Rule Generation)
When `coder.enabled:true`, interfaces with `llama-server` (quantized Q4 GGUF models) to write Vector Remap Language (VRL) logic for the new log template.
- Generates fully functional VRL in ~0.7 seconds (AVX2 optimized).

### 5. `gatekeeper.py` (HitL & Hot-Reloading)
Rules generated by `coder.py` are sent to the Gatekeeper.
- Awaits Human-in-the-Loop (HitL) approval.
- Upon approval, rules are serialized to `/etc/prism/rules` and hot-reloaded into the Rust Data Plane on the fly.

## Configuration (`config.yaml`)
Control Plane behaviors are configured via `config.yaml`:
```yaml
device: cpu
triage: heuristic
coder:
  enabled: false
  host: llama3
  timeout: 2
```

## How to Test
The Python suite contains 20 comprehensive unit and integration tests.

```bash
pytest prism-brain -v
```
To force tests mimicking CPU-only environments without LLM dependencies, prefix with:
```bash
PRISM_DEVICE=cpu pytest prism-brain -v
```
